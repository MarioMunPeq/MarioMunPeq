## Sobre mí

Construyo proyectos personales porque me gusta entender cómo funcionan las cosas. Me interesan especialmente el desarrollo backend, las aplicaciones web, la automatización y el procesamiento de datos con IA.

Disfruto diseñando proyectos que puedan crecer con el tiempo, cuidando tanto la arquitectura como los pequeños detalles de la implementación. Actualmente busco oportunidades donde pueda aportar en backend y sistemas con IA, mientras sigo dedicando tiempo libre a construir herramientas que resuelvan problemas reales.
